# 📘 Student Grade Manager

## 📌 Description
Student Grade Manager is a simple and beginner-friendly Python console application that allows users to manage student records and track their academic performance using the Tunisian grading system (0–20).

## 🎯 Features
- Add new students  
- Add grades to existing students  
- Calculate average grades  
- Assign mentions  
- Determine pass/fail status  
- Display all students sorted by performance  
- Remove students  
- Generate class summary  

## 🧠 Technologies Used
- Python

## 📊 Grading System
- Scale: 0 to 20  
- Pass mark: 10/20
